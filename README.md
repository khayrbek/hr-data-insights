# hr-data-insights

Лендинг **Workforce Intelligence Platform** — платформы, которая объединяет данные о сотрудниках, должностях, структуре, найме, компенсациях и навыках и отвечает на вопросы руководителя о людях и затратах.

Один самодостаточный HTML-файл: без сборщиков, фреймворков и бэкенда.

**Живая версия: https://hr-data.ru/**

## Что на странице

- **Первый экран** — позиционирование и макет интерфейса для руководителя
- **«У вас уже есть данные»** — источники по HR-доменам: кор-системы (1С:ЗУП, SAP HR, БОСС-Кадровик), ATS (Хантфлоу, СкиллАз, Поток, Талантикс), LMS, КЭДО, оценка, хранилища и файлы
- **Подход** — схема из трёх зон: ваши системы → наш слой аналитики → результат
- **Продукт** — шесть категорий вопросов (стоимость персонала, численность и структура, текучесть, найм, компетенции, планирование персонала) и примеры ответов платформы в отдельном окне
- **От цифр к действию** — «было → стало» на примере текучести и рекомендации для руководителя
- **ИИ-аналитик** — вопросы обычным языком; каналы: почта, корпоративный мессенджер, MAX, Telegram
- **Архитектура и совместимость** — модель данных, интеграции из коробки, работа под брендом компании
- **Безопасность** — российские серверы, 152-ФЗ, приказ ФСТЭК № 21, два варианта размещения: on-premise или облако
- **Для кого**, путь решения, **программа для первых клиентов**, команда

## Стек

- `index.html` — разметка, CSS и немного ванильного JS (модальные окна, раскрывающиеся списки). Внешние зависимости — только шрифты Google Fonts (Inter, JetBrains Mono).
- Никаких сборщиков, зависимостей и серверной части.

## Как править

1. Меняем `index.html`.
2. Кладём на сервер: `cp index.html /var/www/hrdata/index.html`.
3. Проверяем на телефоне (390 px) — горизонтальной прокрутки быть не должно.

## Деплой

`deploy/nginx-hr-data.conf` — боевой конфиг nginx: канон `https://hr-data.ru`, `http` и `www` уходят 301 на канон, HSTS, gzip, кэш статики.

```bash
# сертификат на оба имени
certbot certonly --webroot -w /var/www/letsencrypt -d hr-data.ru -d www.hr-data.ru

# применить конфиг
cp deploy/nginx-hr-data.conf /etc/nginx/sites-available/hrdata
ln -sf /etc/nginx/sites-available/hrdata /etc/nginx/sites-enabled/hrdata
nginx -t && systemctl reload nginx
```
